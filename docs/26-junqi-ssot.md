## 1. 棋盘坐标

全盘 **12 行 × 5 列 = 60 格**。

| 行 | 归属 |
|----|------|
| 0～5 | 黑方半场（行 0 = 黑方底线） |
| 6～11 | 红方半场（行 11 = 红方底线） |

列 0（左）～4（右）。

半场各 30 格；布阵可用格 = 30 − 5 行营 = **25**，与每方 25 子匹配。

## 2. 格点类型（附图）

### 2.1 大本营（每方 2）

| 方 | 坐标 |
|----|------|
| 黑 | `(0,1)` `(0,3)` |
| 红 | `(11,1)` `(11,3)` |

### 2.2 行营（每方 5 · 不可布阵 · 不可被攻）

| 方 | 坐标 |
|----|------|
| 黑 | `(2,1)` `(2,3)` `(3,2)` `(4,1)` `(4,3)` |
| 红 | `(7,1)` `(7,3)` `(8,2)` `(9,1)` `(9,3)` |

红 = 黑关于行轴竖直镜像：`(r,c) → (11−r, c)`。

### 2.3 兵站

其余格点均为兵站。前线：行 5（黑）与行 6（红）。

### 2.4 山界

行 5 与行 6 之间仅 **列 0 / 2 / 4** 可通行；列 1、3 不可穿越。

## 3. 连通（走子图）

### 3.1 公路

- 同半场及前线：上下左右相邻格（若格存在）为公路边。
- 山界跨越：`(5,0)↔(6,0)`、`(5,2)↔(6,2)`、`(5,4)↔(6,4)` 为公路（中线实线）或铁路（边线，见下）。
- **行营对角线**：每个行营与斜向四邻（若存在）有公路边（附图 X 线）。

### 3.2 铁路（附图粗虚线 · 非「全网格铁路」）

黑半场铁路环（示意）：

- 横：行 1 列 0–4；行 5 列 0–4  
- 竖：列 0 行 1–5；列 4 行 1–5  

红半场镜像：行 `11−r`。

山界铁路：`(5,0)↔(6,0)`、`(5,4)↔(6,4)`（附图边线为铁路；中线 `(5,2)↔(6,2)` 为公路）。

**行营不阻断铁路**：铁路路径可经过行营格（仍受「格上有子不可跨越」约束）。

> 实现须用显式边表 / 邻接表；禁止用「同行同列任意相邻=铁路」代替附图。

## 5. 布阵

1. 25 子放在己方半场 25 个非行营格（兵站 + 大本营）。
2. **军旗**必须在己方两大本营之一。
3. **地雷**仅己方最后两行（黑 0–1，红 10–11），且不可与军旗同大本营。
4. **炸弹**不可放在己方底线第一行（黑行 0，红行 11）。

---

## 6. 走子

| 情况 | 规则 |
|------|------|
| 军旗 / 地雷 / 已入大本营的子 | 不可再动 |
| 公路 | 可动子每次 1 步（含行营对角公路） |
| 铁路 · 普通子 | 沿铁路**直线**任意步，不拐弯 |
| 铁路 · 工兵 | 沿铁路任意走，**可拐弯** |
| 行营内出发 | 本步只许公路 1 格（即使格在铁路上） |
| 阻挡 | 路径上任一方棋子均不可跨越 |
| 行营 | 敌方不可攻击行营内的子；可走进空行营 |

---

## 7. 吃子与扛旗

等级链：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵。

| 进攻 \ 防守 | 结果 |
|-------------|------|
| 等级高 vs 低 | 进攻胜，进占该格 |
| 同级 | 同尽，格空 |
| 任一方为炸弹（另一方非军旗） | 同尽 |
| 工兵 vs 地雷 | 工兵胜（排雷） |
| 非工兵非炸弹 vs 地雷 | 进攻方死，地雷留 |
| 炸弹 vs 地雷 | 同尽 |
| **任意己方棋子 vs 军旗** | **进攻方胜局（扛旗）**；**无需清雷** |
| 炸弹 vs 军旗 | 视为扛旗胜局（直接胜，不同尽） |

暗棋：对方只见表层「敌子」；碰撞由服务端按真实身份判定后广播结果（胜/负/同尽），**不向对手泄露未参战棋子身份**。参战双方是否公开对方死子军衔：本切片 **公开本次碰撞双方军衔**（便于理解光效）。

---

## 8. 特殊

1. **司令阵亡**（被吃或同尽）：该方立即向对方公开军旗坐标。  
2. **行营免战 / 行营离营限 1 格**：见 §6。  
3. **进入非军旗大本营**：棋子锁定，不可再动。  
4. **进入军旗所在大本营**：立即获胜。

---

## 9. 胜负

| 条件 | 结果 |
|------|------|
| 一方军旗被走进（扛旗） | 进攻方胜 |
| 一方无任何可移动棋子 | 该方负 |
| 一方断线 / 认输 | 对方胜 |
